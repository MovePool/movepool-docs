# Gamification

MovePool rewards consistent participation with XP, levels, streaks, and badges.

---

## XP (Experience Points)

Earn XP by:

- **Depositing** → XP based on amount
- **Entering Draws** → XP per entry
- **Winning Prizes** → Bonus XP
- **Daily Logins** → Streak bonuses

---

## Levels

Your level is calculated from total XP:

| Level | XP Required |
| ----- | ----------- |
| 1     | 0           |
| 5     | 500         |
| 10    | 2,000       |
| 20    | 10,000      |
| 50    | 100,000     |
| 100   | 1,000,000   |

Level up to unlock new **Badge Frames** for your profile!

---

## Streaks

Keep a streak by participating daily:

| Streak Days | XP Multiplier |
| ----------- | ------------- |
| 3 days      | 1.1x          |
| 7 days      | 1.25x         |
| 14 days     | 1.5x          |
| 30 days     | 2x            |

{% hint style="success" %}
**Pro Tip:** Don't break your streak! Log in daily to maximize XP.
{% endhint %}

---

## Badges

Permanent achievements stored on-chain:

| Badge            | Requirement        |
| ---------------- | ------------------ |
| 🎯 First Entry   | Enter any draw     |
| 🏆 First Win     | Win any prize      |
| 🔥 Week Warrior  | 7-day streak       |
| 💎 Diamond Hands | 30-day streak      |
| 🐋 Whale         | Deposit 1000+ MOVE |

Badges are visible on your profile and in the leaderboard.

---

## Leaderboard

Compete with other players on the monthly XP leaderboard:

- Resets on the 1st of each month (UTC)
- Top players displayed on `/leaderboard`
