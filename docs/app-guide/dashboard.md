# Dashboard Overview

Your MovePool dashboard is your command center for managing deposits and tracking prizes.

## Main Sections

### Balance Card

Shows your total deposit value in the vault. This is your **protected principal** that never goes down.

### Pool Cards

Two lottery pools with live countdowns:

- **Quick Draw** — Weekly draws (70% of yield)
- **Jackpot** — Monthly draws (30% of yield)

Each card shows:

- Current prize pool
- Your ticket count
- Time until next draw

### Recent Activity

A log of your deposits, withdrawals, and prize wins.

## Navigation

| Menu Item     | Description                   |
| ------------- | ----------------------------- |
| **Overview**  | Main dashboard view           |
| **Deposit**   | Add funds to the vault        |
| **Withdraw**  | Take out your funds anytime   |
| **Stats**     | Your XP, level, and streaks   |
| **Profile**   | Wallet info and referral link |
| **Winners**   | Past winner history           |
| **Analytics** | TVL and prize charts          |

## Demo Tools (Operators Only)

If you're a protocol operator testing the app, expand **Demo Tools** at the bottom-right to manually trigger keeper runs.
