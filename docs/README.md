MovePool is a **zero-loss, arcade-style savings protocol** on Movement Testnet.

Users deposit **MOVE**, get tickets proportional to deposits (**1 MOVE = 1 ticket**), and compete for prizes funded by yield—**not principal**.

## Quick links

- App: https://movepool.vercel.app
