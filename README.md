# MovePool Docs (GitBook)

This repository contains the MovePool documentation source for GitBook using a **docs-as-code** workflow.

## GitBook configuration

The `.gitbook.yaml` at the repo root points GitBook to the `docs/` directory:

- Docs root: `docs/`
- Landing page: `docs/README.md`
- Table of contents: `docs/SUMMARY.md`

## Getting started

1. Create a GitBook Site + Space.
2. Enable **GitHub Sync** for the Space.
3. Select this repository + branch.
4. Choose initial sync: **GitHub → GitBook**.

Reference: `docs/runbooks/gitbook-sync.md`
